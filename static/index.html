📄 PDF Giáo Án

Cách dùng (4 bước):
  1. Chọn file PDF (đề, giáo án…).
  2. Bấm “Đọc và chuyển”, chờ máy đọc từng trang.
  3. Xem lại: trang gốc ở bên cạnh, sửa chữ hoặc công thức nếu máy đọc sai.
  4. Bấm “Tải file Word”.

Cài đặt

Khóa Gemini (miễn phí) — để máy đọc được chữ và công thức:

  1. Mở aistudio.google.com/app/apikey, đăng nhập Google.
  2. Bấm “Create API key”, chép chuỗi khóa.
  3. Dán vào ô dưới đây. Khóa chỉ lưu trên máy này.
