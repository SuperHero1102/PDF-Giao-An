📄 PDF Giáo Án

Cách dùng (4 bước):
  1. Chọn file PDF (đề, giáo án…).
  2. Bấm “Đọc và chuyển”, chờ máy đọc từng trang.
  3. Xem lại: trang gốc ở bên cạnh, sửa chữ hoặc công thức nếu máy đọc sai.
  4. Bấm “Tải file Word”.
Bấm vào đây để chọn file PDF
hoặc kéo thả file vào ô này (tối đa 100MB)
📎 — trang
File dài: máy đọc lần lượt từng trang (khoảng 10–30 giây/trang, 3 trang cùng lúc). Khi đang đọc hãy để màn hình sáng và đừng đóng trang. Nếu hết lượt miễn phí của Gemini trong ngày, máy tự dừng và giữ lại các trang đã đọc; hôm sau bấm “Đọc các trang còn thiếu” để làm tiếp.
Đang xử lý…

Mỗi trang mất khoảng 10–30 giây. Giữ màn hình sáng, đừng đóng trang. Trang nào đọc xong đều được lưu ngay.

Lưu thành PDF

Bản in sẽ mở ở thẻ mới, gồm mọi trang đã đọc. Ở thẻ đó bấm nút “In / Lưu thành PDF”, rồi:

  • iPhone: dùng hai ngón tay phóng to bản xem trước → bấm nút Chia sẻ → “Lưu vào Tệp”.
  • Android: chọn “Lưu dưới dạng PDF” → bấm biểu tượng tải xuống.
  • Máy tính: ở mục “Máy in / Đích đến” chọn “Lưu dưới dạng PDF”.

Bố cục có thể hơi khác file Word. Cần giống hệt Word thì hãy tải file Word.

Cài đặt

Khóa Gemini (miễn phí) — để máy đọc được chữ và công thức:

  1. Mở aistudio.google.com/app/apikey, đăng nhập Google.
  2. Bấm “Create API key”, chép chuỗi khóa.
  3. Dán vào ô dưới đây. Khóa chỉ lưu trên máy này.
